2. What encoding changes
Initial B0 directions reverse in all 16 encoding pairs. Δ reverses in 14/16, trained Bt in only 6/16, including nine pairs where Δ reverses without Bt reversing. Initial input geometry is therefore crucial to interpreting training increments. Both cycle-encoded GRU exceedance/deficiency sources achieve 100% analysis accuracy, and one-line sources are also near 100%; Δ still reverses while Bt remains positive in both encodings. Thus not every encoding difference can simply be attributed to failure to learn the task. Other cycle tasks learn substantially less well. Descriptively, 61/64 sources exceed training-defined length modes and three do not; there is no comprehensive mastery match across encodings. Configuration capacities are unmatched, so no pure architecture effect is claimed.
