Cache evidence and exact scope
evaluation/index.json contains 256 logical records=64 models × initial/trained × validation/test. All arrays are .npy read-only mmaps, with file SHA and dtype/shape/bytes content SHA. The separately saved pre-task final_norm prefix_final is primary; packed-layer final_norm must not replace earlier primary arrays. Four blocks/four GRU layers plus final_norm form a five-layer package; embedding is not fabricated as a package layer.
Each earlier NPZ norm/prob/pred field is decoded once. original_array_conversion_checks saves original-content SHA→new NPY-content SHA and verifies elementwise np.array_equal. Initial CE was not cached for the original 16 models and remains explicitly missing; trained CE, final-batch loss, or CE from another 8k model cannot fill it.
Initial head probabilities, predictions, and CE for the 48 new models use task-specific forward passes from genuine step-0, not task-answer reuse from shared hidden states. Initial layer packages and prefixes are aliased only after elementwise equality over all original anchors/three actions, retaining source run_id and array descriptions.
Independent checks cover each new source at initial/trained states, test lengths 10/20/30, and the first 8 samples for each identity/complement/inverse action. They use full prompts for the first 128 samples at that length, with exactly the production extraction shape. Manual forward results are compared directly against saved layer packages and independent prefixes at tolerance 2e-5. Prompts include task and equals tokens; sequence width is 2*max(n)+6. The number 128 counts samples, not padding to 128 tokens. Validation caches have no independent sampled check and only reference this test-check scope.
output_prob=softmax(logits[:,0:31]) is conditional on valid numeric tokens 0..30; prediction argmax and answer CE use the full 188-token vocabulary. The +1 right-answer offset for components applies only to relation comparison/grouping, not actual source-task supervision or CE labels.
